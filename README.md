# PadKeys

Native Android app (Kotlin + Jetpack Compose).

## Paano makuha ang APK
1. Pumunta sa tab na **Actions** sa repo na ito.
2. Buksan ang pinakabagong run na "Build APK" (hintayin ang berdeng check).
3. Sa ibaba, sa **Artifacts**, i-download ang `PadKeys-debug-apk`.
4. I-extract ang zip at i-install ang `app-debug.apk` sa Android phone.

Para mag-build ulit nang mano-mano: **Actions > Build APK > Run workflow**.
